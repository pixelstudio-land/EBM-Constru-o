# EBM Construção - Máquina de Orçamentos 🚀

Landing page com calculadora inteligente de orçamentos online para **EBM Construção**, especializada em pisos vinílicos e serviços de instalação profissional.

## 🛠️ Tecnologias
- HTML5 / CSS3 / JavaScript Vanilla
- Meta Pixel integrado para rastreamento de Leads
- Integração direta com WhatsApp

## 📋 Regras de Negócio e Serviços
- **Piso Vinílico Colocado (Material + Instalação):** R$ 160,00/m²
- **Mão de Obra de Instalação (Somente Instalação):** R$ 70,00/m²
- **Visita Técnica:** Gratuita
- **Condição Especial:** Até 5% de desconto para pagamento à vista

## 📁 Estrutura de Arquivos
```text
|-- index.html          # Esqueleto da página e calculadora
|-- assets/             
|   |-- fundo.jpg       # Imagem de fundo da seção hero
|   |-- logo.png        # Logo transparente da EBM Construção
|   |-- logo-original.jpeg
|-- css/
|   |-- global.css      # Estilos globais e componentes
|   |-- theme.css       # Cores e variáveis da marca (Dourado EBM: #E6AE29)
|-- js/
|   |-- config.js       # Configuração de preços, textos, bônus e WhatsApp
|   |-- main.js         # Lógica da calculadora e disparo para WhatsApp
|   |-- pixel.js        # Meta Pixel de rastreamento
```
